# Karwa Phase 76 — تحسين وضع القيادة والتتبع الحي

- عند وجود طلب نشط تدخل خريطة الكابتن تلقائيًا في وضع القيادة مع متابعة الموقع وتكبير مناسب للطريق القادم.
- اتجاه المؤشر يعتمد على `GPS heading`، وعند غيابه يُحسب الاتجاه من حركة آخر نقطتين، مع تنعيم دائري لمنع اهتزاز 0/360 درجة.
- السهم والسيارة والدراجة أصبحت مؤشرات اتجاهية فعلية: الزاوية `0°` تعني الشمال، ثم يدور الشكل مع اتجاه حركة الكابتن.
- اختيار شكل المؤشر محفوظ من إعدادات الكابتن: **سهم / سيارة / دراجة**، ويُرسل نفس الاختيار إلى العميل.
- أثناء الطلب النشط يُرسل موقع الكابتن إلى `orders/{orderId}/tracking/current` كل نحو **ثانيتين** عند توفر GPS بدقة مقبولة.
- العميل يشترك بالتتبع عبر `onSnapshot` ويحرك مؤشر الكابتن بسلاسة بين التحديثات، مع إظهار الاتجاه والسرعة ودقة GPS.
- إعادة حساب مسار الملاحة أصبحت أسرع: بعد نحو **5 ثوانٍ** أو عند التحرك قرابة **30 مترًا** بدل الانتظار لمسافة أكبر.
- لا توجد حاجة لتعديل Cloud Functions أو قواعد Firestore الحالية لهذه الإضافة؛ التتبع يستخدم نفس مستند `tracking/current` المسموح للكابتن المعين بالكتابة فيه.
