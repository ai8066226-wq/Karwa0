# كروة Phase 72 — طلب صنف واحد أو عدة أصناف

الإصدار: 2.2.3

## الجديد
- يستطيع العميل إنشاء طلب يحتوي على صنف واحد أو عدة أصناف من نفس المطعم أو مزود الخدمة.
- حد أقصى 8 أصناف في الطلب الواحد لحماية الأداء والتحقق الأمني.
- لكل صنف كمية ووحدة مستقلة: قطعة، وجبة، نفر، كيلو، عبوة، لتر، متر، ساعة أو يوم.
- تظهر سلة واضحة قبل الإرسال مع سعر كل صنف والإجمالي.
- يمكن حذف أي صنف من السلة قبل الإرسال.
- إذا أضاف العميل الصنف نفسه مرة ثانية يتم تحديث كميته بدل تكراره.
- لا يمكن خلط أصناف من مطعمين أو نشاطين مختلفين داخل الطلب الواحد.
- أجرة التوصيل تُحسب مرة واحدة للطلب كاملًا، وتساوي أعلى أجرة توصيل بين الأصناف المختارة.
- التوصيل يتاح فقط إذا كانت جميع الأصناف المختارة تدعم التوصيل.
- مزود الخدمة يرى جميع الأصناف والكميات والأسعار داخل بطاقة الطلب.
- يظل العميل قادرًا على تعديل كميات الأصناف أو حذف صنف قبل استلام مندوب التوصيل، ثم يقفل التعديل عند الاستلام.
- تم تحديث Firestore Rules للتحقق من كل صنف مقابل قائمة وأسعار مزود الخدمة، مع بقاء دعم الطلبات القديمة ذات الصنف الواحد.

## النشر
ارفع ملفات السيرفر ثم انشر `firestore.rules` الجديدة.
