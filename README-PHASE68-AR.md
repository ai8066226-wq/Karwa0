# كروة Phase 68 — إصلاح حلقة التحديث التلقائي

الإصدار: **2.1.9**

تم إصلاح حالة ظهور رسالة «يتوفر تحديث جديد لكروة» ثم إعادة تحميل التطبيق بصورة متكررة.

السبب في Phase 67 كان عدم تطابق رقم البناء داخل `pwa.js` (Phase 66 / 2.1.7) مع `version.json` (Phase 67 / 2.1.8).

الإصلاحات:
- توحيد رقم النسخة إلى Phase 68 / 2.1.9.
- تطبيق Android يعتمد على فاحص النسخة الأصلي فقط ولا يسمح لـ pwa.js بإعادة تحميل WebView.
- pwa.js المحلي داخل Android يُحمّل من التطبيق نفسه دائمًا حتى لو كانت نسخة السيرفر قديمة جزئيًا.
- في المتصفح/PWA يوجد حارس يمنع أكثر من Reload واحد لنفس النسخة المستهدفة حتى عند وجود ملفات سيرفر غير متطابقة.
- إلغاء Reload إضافي عند `controllerchange` للخدمة العاملة.

للنشر ارفع جميع ملفات حزمة السيرفر معًا، خصوصًا `pwa.js` و`version.json` و`sw.js`.
