# كروة Phase 74 — حماية المحفظة والرسوم حسب العملية

الإصدار: 2.2.5

تمنع هذه المرحلة تنفيذ أي عملية مالية إذا كان رصيد الحساب أقل من الرسم الذي تحدده الإدارة للعملية نفسها.

الإدارة تستطيع تحديد رسوم منفصلة لعميل التكسي، عميل التوصيل، عميل المطاعم والخدمات، كابتن التكسي، كابتن التوصيل، المطاعم، الخدمات الأخرى، ورسم نشر النشاط.

يتم احتساب الرصيد المتاح من الرصيد المشحون إضافة إلى الرصيد المجاني إذا كان ما زال صالحًا. عند عدم كفاية الرصيد لا تُنفذ العملية ولا يحدث خصم جزئي.

يجب نشر `firestore.rules` مع ملفات السيرفر.
