# كروة Phase 71 — تعديل الطلب قبل استلام مندوب التوصيل

أضيفت إمكانية تعديل طلب المطعم أو الخدمة من قبل صاحب الطلب فقط قبل استلام مندوب التوصيل فعليًا.

## السلوك
- يشمل مطاعم/خدمات `serviceRequests` وكذلك **طلبات توصيل الأغراض المباشرة** `parcel`.
- يظهر زر **تعديل الطلب** للعميل صاحب الطلب فقط.
- في المطاعم والخدمات يمكن تعديل الكمية وملاحظات الطلب.
- في توصيل الأغراض يمكن تعديل عنوان الاستلام والتسليم واسم/هاتف المستلم والملاحظات، بينما تبقى الأجرة نفسها.
- يبقى التعديل متاحًا إذا قبل المندوب الطلب أو وصل إلى النشاط، ما دام لم يؤكد الاستلام بعد.
- لحظة انتقال طلب التوصيل إلى `statusIndex = 3` (تم التحقق من رمز الاستلام) تقفل التعديلات نهائيًا.
- إذا كان الطلب بلا مندوب بعد، يبقى التعديل متاحًا أثناء `pending` أو `accepted`.
- السعر يعاد حسابه من سعر الوحدة الأصلي والكمية الجديدة، ولا يمكن للعميل تغيير سعر الوحدة أو أجرة التوصيل.
- عند وجود `deliveryOrderId` يتم تحديث `serviceRequests.totalPrice` و `orders.serviceTotal` في Firestore Transaction واحدة.
- يسجل `customerEditedAt` و `customerEditCount` ويظهر التنبيه لدى مزود الخدمة.

## النشر
ارفع ملفات الواجهة ثم انشر `firestore.rules` الجديدة. لا تحتاج هذه الميزة إلى Cloud Functions.
