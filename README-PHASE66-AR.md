# كروة Phase 66 — نظام التقييم الموحد

تمت إضافة نظام تقييم احترافي لجميع العملاء بعد اكتمال الخدمة:

- تقييم كابتن التكسي بعد اكتمال الرحلة.
- تقييم كابتن التوصيل بعد اكتمال أي طلب توصيل.
- تقييم المطعم أو مزود الخدمة بعد اكتمال طلب الخدمة.
- إذا كان طلب الخدمة يتضمن توصيلًا، يظهر تقييم منفصل لمزود الخدمة وتقييم منفصل لكابتن التوصيل.
- التقييم من 1 إلى 5 نجوم، مع ملاحظات سريعة وتعليق اختياري حتى 300 حرف.
- يمنع Firestore تكرار التقييم لنفس الطلب أو تعديله بعد الإرسال.
- لوحة الإدارة تعرض المتوسط العام، وأعداد تقييمات التكسي والتوصيل والخدمات، مع فلترة وتفاصيل كل تقييم.
- تقييمات العميل لا يمكن إرسالها إلا للطلبات المكتملة المملوكة لنفس الحساب.

## النشر
انشر ملفات الواجهة وقواعد Firestore الجديدة. إذا كنت تستخدم Firebase CLI:

```bash
firebase deploy --only hosting,firestore:rules
```

لا تحتاج ميزة التقييم إلى Cloud Functions.
