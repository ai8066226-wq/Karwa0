# كروة Phase 73 — باركود رمز الوصول والمسح بالكاميرا

الإصدار: 2.2.4

- يظهر باركود Code-128 صغير تحت رمز التحقق لدى العميل ويحمل نفس الرمز المكوّن من 4 أرقام.
- يظهر للكابتن زر «مسح باركود العميل» في مرحلة التحقق المناسبة للتكسي والتوصيل.
- يفتح ماسح الكاميرا الخلفية، ويقرأ Code-128 تلقائيًا عندما يدعمه WebView/المتصفح.
- بعد قراءة باركود صحيح يتم استخدام نفس تحقق OTP الحالي ولا يتم إنشاء مسار أمان منفصل.
- إذا تعذر المسح أو لم يدعم الجهاز BarcodeDetector يبقى الإدخال اليدوي متاحًا من نفس النافذة.
- لا تحفظ صور الكاميرا ولا ترفعها إلى Firebase.
- تطبيق Android يطلب صلاحية الكاميرا عند أول استخدام للماسح.
