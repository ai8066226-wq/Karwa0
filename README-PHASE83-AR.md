# Karwa Phase 84 / 2.3.5 — قمرة قيادة مستوحاة من Waze

- حُذفت بطاقة ملخص الاتجاهات السفلية من شاشة الكابتن.
- بقيت بطاقة التوجيه التالي والتنبيه الصوتي قبل المنعطف.
- بقي مسار الخريطة ظاهرًا بعد «تم الوصول» مع تنبيه الوصول الصوتي.
- يعاد حساب المسار من موقع الكابتن الحالي عند الانحراف أو تغيّر مرحلة الرحلة.
- خريطة القيادة تستخدم مسارًا أزرق بحد أبيض، شريط توجيه علويًا، ومؤشر سرعة عائمًا أسفل الخريطة.
