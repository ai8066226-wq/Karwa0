# Karwa Phase 61

تحقق بلاغات الطريق يعمل مباشرة عبر Firestore Transaction + Security Rules، بدون Cloud Function خاصة بهذه الميزة.

- تنبيه قبل البلاغ عند 150م.
- نافذة تحقق لمدة 6 ثوانٍ عند الوصول.
- نعم: يبقى البلاغ وتبدأ جولة تحقق جديدة.
- لا الأولى: يبقى البلاغ بانتظار كابتن ثانٍ مختلف.
- لا الثانية من كابتن مختلف: يصبح `active=false` ويختفي لحظيًا من خرائط كروة.
- كل تصويت يُسجل في `roadReportVerifications`.
- قواعد Firestore تتحقق من دور الكابتن، حداثة موقعه، القرب من البلاغ، وتسلسل التحقق.

## النشر

`firebase deploy --only hosting,firestore:rules`
