# Karwa Phase 82 / 2.3.3

- إبقاء مسار الملاحة ظاهرًا بعد «تم الوصول» مع تنبيه الوصول الصوتي، وإعادة رسم المسار عند تغيّر مرحلة الرحلة أو الانحراف عنه.
- إعادة رسم مسار الكابتن تلقائيًا عند الانحراف أو تجاوز المسار، من موقعه الحالي إلى هدف الرحلة.
- ربط الحسابات الجديدة ببصمة Android خاصة بتطبيق كروة بدل IMEI المقيد على Android الحديث.
- حساب واحد نشط لكل جهاز/تطبيق مع ترحيل الحسابات القديمة عند أول دخول من التطبيق.
- طلب استبدال الجهاز يُنشأ تلقائيًا عند محاولة الدخول من هاتف جديد، ولا يصبح الهاتف الجديد صالحًا حتى اعتماد الإدارة.
- معرفات الأجهزة لا تظهر في واجهات العميل أو الكابتن أو الخدمات؛ تظهر فقط في لوحة الإدارة.
- بدون Cloud Functions؛ يعتمد على Firestore Rules + Hosting.
