# Karwa Phase 80 / 2.3.1

نسخة Firestore مباشرة بدون Cloud Functions.

## إصلاح التفعيل
- إصلاح قبول وتفعيل حسابات الكابتن والخدمات الأخرى من لوحة الإدارة.
- تدعم الإدارة الطلبات القديمة التي فقدت مستند `users/{uid}` وتعيد إنشاء ملف المستخدم بأمان عند التفعيل.
- تنظيف القيم القديمة/الناقصة قبل إنشاء ملف الكابتن أو مزود الخدمة حتى لا يفشل Firestore بسبب قيمة `undefined`.
- استخدام `application.userId` كمرجع أساسي للحساب بدل افتراض أن رقم مستند الطلب هو UID دائمًا.
- رسائل الخطأ في لوحة الإدارة أصبحت تفرق بين رفض القواعد والبيانات القديمة.

## النشر
1. `firebase deploy --only firestore:rules`
2. `firebase deploy --only hosting`

لا توجد Cloud Functions في هذه النسخة.
