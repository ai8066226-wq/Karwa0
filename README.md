# Karwa0

تطبيق عربي للحجز والتوصيل يعمل على GitHub Pages مع Firebase Authentication وCloud Firestore.

## فصل الحسابات

- `customer`: تطبيق العميل `index.html` فقط.
- `driver`: بوابة الكابتن `driver.html` فقط.
- `admin`: لوحة الإدارة `admin.html` فقط.

لا يمكن للحساب الواحد استخدام أكثر من دور في الوقت نفسه. يبدأ الحساب الجديد كعميل، ويمكنه إرسال طلب انضمام من بوابة الكابتن. عند قبول المدير للطلب يتغير دوره إلى كابتن فقط.

يحفظ كل تطبيق جلسته محليًا باسم مستقل، لذلك يمكن إبقاء حساب العميل والكابتن والمدير مسجلة في المتصفح نفسه دون أن تستبدل إحداها الأخرى.

## إدارة الجودة

- يستطيع العميل تقييم الكابتن من نجمة إلى خمس نجوم بعد اكتمال الرحلة فقط، ولمرة واحدة لكل رحلة.
- يرى الكابتن متوسط تقييماته وعددها والتنبيهات الإدارية مباشرةً.
- يستطيع المدير إرسال تنبيه، حظر الكابتن، أو إعادة تفعيله من لوحة الإدارة.
- يمنع Firestore الكابتن المحظور من الاتصال وقبول الطلبات وتحديث الرحلة أو إرسال الموقع.
- تعرض لوحة الإدارة أحدث التقييمات وحالة كل كابتن وعدد التنبيهات.

## المسار والتسعير والتقارير

- يحدد العميل نقطة الانطلاق والوجهة مباشرةً على الخريطة.
- يحسب التطبيق مسافة الطريق والوقت المتوقع، مع تقدير احتياطي عند تعذر خدمة المسارات.
- يتغير سعر المشوار حسب فئة المركبة والمسافة والوقت، وتُسجل عمولة المنصة وصافي الكابتن داخل الطلب.
- تُرتب الطلبات المتاحة للكابتن حسب قرب نقطة الانطلاق عند تشغيل موقعه.
- تعرض لوحة الإدارة إجمالي إيرادات الرحلات المكتملة، عمولة كروة، صافي الكباتن، متوسط الرحلة، والإلغاءات.
- عمولة المنصة الحالية 15%، وهي معرفة في `app.js` وقواعد `firestore.rules`.

## النشر

ارفع ملفات المشروع إلى جذر مستودع GitHub Pages، ثم استبدل محتوى صفحة Firestore Rules كاملًا بمحتوى `firestore.rules` واضغط Publish.

لاختبار الرحلة استخدم حساب عميل وحساب كابتن منفصلين، ويفضل فتحهما في متصفحين مختلفين.
