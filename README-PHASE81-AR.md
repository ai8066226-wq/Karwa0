# Karwa Phase 81 / 2.3.2 — إعادة المسار وربط الجهاز

## الملاحة
يراقب التطبيق بعد الكابتن عن خط المسار مع مراعاة دقة GPS. عند ثبوت الانحراف في قراءتين متتاليتين يعيد Valhalla/OSRM حساب الطريق فورًا من موقع الكابتن الحالي إلى نقطة الوصول ويحدث تعليمات المنعطفات.

## حماية الحساب بالجهاز
Android 10+ يمنع تطبيقات الطرف الثالث العادية من قراءة IMEI، لذلك تستخدم النسخة معرف ANDROID_ID الخاص بالتطبيق/التوقيع ثم ترسل SHA-256 فقط بصيغة KDW1. المعرف الخام لا يُحفظ في Firestore.

الحساب الجديد يُنشأ مع deviceBindings وaccountDeviceLinks وdeviceAccess في عملية Firestore واحدة. إذا كان الجهاز مستخدمًا لحساب آخر تفشل العملية ولا يبقى حساب Auth ناقص. الحسابات القديمة ترتبط بأول هاتف Android تدخل منه بعد Phase 81.

عند دخول حساب مرتبط من هاتف جديد ينشئ التطبيق deviceChangeRequests تلقائيًا ثم يمنع الجلسة. الإدارة وحدها ترى المعرف القديم والجديد ويمكنها الموافقة على الاستبدال أو رفضه. عند الموافقة يُلغى deviceAccess للهاتف القديم ويُنشأ وصول للهاتف الجديد.

## النشر
1. انشر firestore.rules أولًا.
2. انشر Hosting.
3. لا توجد Cloud Functions.
