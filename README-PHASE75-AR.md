# Karwa Phase 75 — وضع القيادة والاتجاه الحي

- وضع قيادة تلقائي للكابتن عند وجود طلب نشط مع تكبير 17 وإزاحة الكاميرا للأمام لإظهار الطريق القادم.
- اتجاه الكابتن يحسب من GPS heading أو من حركة آخر نقطتين عند غياب heading.
- تنعيم دائري للاتجاه لمنع اهتزاز السهم عند 0/360 درجة.
- اختيار مؤشر الكابتن من الإعدادات: سهم، سيارة، دراجة.
- شكل المؤشر ينتقل مع التتبع إلى العميل ويظهر بنفس الاتجاه الحي.
- تحديث تتبع الكابتن كل 2.5 ثانية أثناء الطلب النشط، و5.5 ثانية خارج الطلب.
- العميل يرى اتجاه البوصلة والسرعة ودقة GPS مع حركة ناعمة للمؤشر.
- لا يتطلب Cloud Functions أو تعديل Firestore Rules لأن tracking/current يسمح للكابتن المعيّن بالكتابة.
