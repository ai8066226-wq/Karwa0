# Phase 86 — صور واجهة الخدمة والمنتجات

- أضيفت صورة اختيارية لواجهة النشاط وصورة اختيارية لكل خدمة/منتج.
- الصور تُضغط داخل الجهاز/المتصفح ثم تُحوّل إلى `WebP` قبل الرفع.
- الحد الأقصى النهائي لكل صورة هو **50 KB** وتتحقق منه الواجهة وقواعد Firebase Storage معًا.
- الصور الديناميكية تحفظ في Firebase Storage تحت `service-media/{uid}/cover` و `service-media/{uid}/items`، بينما تبقى ملفات المشروع المصدرية في GitHub/المستودع كالمعتاد.
- عند حذف منتج ثم حفظ التغييرات، تحذف صورته من Storage. وعند استبدال/حذف صورة الواجهة تحذف الصورة القديمة بعد نجاح حفظ Firestore.
- أضيفت دالة `window.KarwaServiceMedia.deleteAllKnownForCurrentProfile()` لتنظيف كل الصور المعروفة لملف النشاط عند ربط حذف النشاط بالكامل مستقبلًا.
- تظهر الصور الجديدة في بطاقة النشاط، بطاقات المنتجات/الوجبات، نافذة التفاصيل، ومعاينة مزود الخدمة.

## النشر

انشر **Storage Rules** الجديدة مع ملفات الويب، وإلا سيرفض Firebase رفع الصور:

```bash
firebase deploy --only firestore:rules,storage,hosting
```

> GitHub Pages/مستودع GitHub ليس مخزن رفع حيًا آمنًا من داخل تطبيق المستخدم؛ وضع GitHub token داخل JavaScript سيكشفه للمستخدمين. لذلك استخدم المشروع Firebase Storage الموجود أصلًا للصور المرفوعة.
