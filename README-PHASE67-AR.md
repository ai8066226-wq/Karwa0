# كروة Phase 67 — نظام الكميات ووحدات التسعير

- يحدد العميل الكمية قبل طلب أي وجبة أو خدمة.
- المطاعم والخدمات تدعم: قطعة/طلب، وجبة، نفر، كيلوغرام، عبوة/باكيت، لتر، متر، ساعة، يوم.
- الوزن واللتر والمتر والساعة تقبل كسورًا حسب الوحدة، بينما القطع والوجبات والنفرات والعبوات والأيام أعداد صحيحة.
- يحسب الإجمالي قبل الإرسال ويخزن الكمية ووحدة التسعير وسعر الوحدة والمجموع الفرعي.
- العناصر القديمة التي لا تحتوي unit تستمر افتراضيًا بوحدة قطعة/طلب.
- يجب نشر firestore.rules الجديدة مع ملفات Hosting.
