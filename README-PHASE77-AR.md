# Karwa Phase 77 — ضبط طلبات الشحن والإشعارات والبحث عن الكباتن

## الجديد
- طلب شحن واحد معلّق لكل حساب (عميل / كابتن / خدمات أخرى). يُنشأ الطلب مع قفل Firestore ذري، ولا يمكن إنشاء طلب ثانٍ حتى تعتمد الإدارة الطلب أو ترفضه.
- عند اعتماد/رفض طلب الشحن تُحرّر الإدارة القفل تلقائيًا، فيستطيع المستخدم إرسال طلب جديد.
- إشعار الكابتن للطلب الجديد يعرض اسم العميل، وبطاقة الطلب تعرض اسم العميل أيضًا.
- مركز إشعارات الكابتن يدعم حذف إشعار منفرد وحذف الكل.
- مركز الإشعارات العام المستخدم لدى العميل والخدمات والإدارة يدعم حذف كل إشعار منفرد، إضافة إلى مسح السجل الموجود سابقًا.
- بحث حي في إدارة الكباتن بالاسم، الهاتف، البريد، المدينة، رقم اللوحة، المركبة أو نوع الخدمة.

## النشر
1. انشر `firestore.rules` أولًا لأن طلبات الشحن الجديدة تعتمد على مجموعة `topupLocks`.
2. انشر الاستضافة.
