# Karwa Phase 80 / 2.3.1 — ملاحة الكابتن الدوارة والتنبيهات الصوتية

- تدور خريطة الكابتن مع اتجاه المركبة أثناء وجود طلب نشط، ويبقى مؤشر الكابتن متجهًا إلى أعلى الشاشة.
- أزيلت بطاقة «وضع القيادة» من واجهة الخريطة، وبقيت السرعة فقط داخل دائرة بجانب جرس الإشعارات.
- تنبيه صوتي اتجاهي قبل المنعطف بحوالي 100 متر مع نطق عربي. يستخدم Android TextToSpeech الأصلي، والويب SpeechSynthesis عند توفره.
- لا يستطيع العميل إلغاء رحلة التكسي بعد نجاح قراءة رمز بدء الرحلة وانتقال الحالة إلى «الرحلة جارية». القفل موجود في الواجهة وفي Firestore Rules.
- لا توجد Cloud Functions.
