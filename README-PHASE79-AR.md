# Karwa Phase 79 / 2.3.0 — إصلاح قبول وتفعيل الحسابات

هذه المرحلة تعالج خطأ «تعذر تنفيذ العملية. تحقق من قواعد Firestore» عند قبول الكابتن أو مزود الخدمة.

السبب الذي تمت معالجته: بعض الطلبات القديمة قد تكون موجودة بينما مستند المستخدم `users/{uid}` غير موجود؛ Phase 78 كانت تسمح للإدارة بتحديث المستخدم فقط، فيُرفض إنشاء مستند مفقود وتفشل الدفعة بالكامل.

التغييرات:
- قاعدة آمنة تسمح للإدارة بإنشاء ملف مستخدم مفقود أثناء التفعيل فقط لدور `driver` أو `serviceProvider` مع حقول رصيد سليمة.
- استعادة ملف المستخدم تلقائيًا للحسابات القديمة.
- تنظيف الحقول قبل الحفظ ومنع `undefined`.
- الاعتماد على `userId` داخل طلب التسجيل لتحديد UID الحقيقي.
- إبقاء النسخة بدون Cloud Functions.

انشر قواعد Firestore أولًا ثم Hosting.
