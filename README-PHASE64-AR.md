# كروة Phase 65 — الثيمات التلقائية للأنشطة

الإصدار: **2.1.6**

## الجديد
- 24 ثيمًا بصريًا احترافيًا محفوظًا مسبقًا في جذر السيرفر مباشرة بدون مجلدات فرعية، بدون أسماء أو نصوص داخل الصور.
- اختيار الثيم تلقائيًا حسب نوع وتصنيف الخدمة، مع دعم التصنيفات العربية الحرة مثل: مطعم، مقهى، بيتزا، حلويات، مخبز، بقالة، صيدلية، عيادة، سباك، كهربائي، تكييف، تنظيف، مكافحة حشرات، صالون، سبا، لياقة، غسيل سيارات، حيوانات، سفر، توصيل، شحن، متاجر وصيانة.
- اسم النشاط ووصفه يبقيان بيانات ديناميكية فوق التصميم ولا يتم حرقهما داخل صورة الثيم.
- المطاعم والخدمات القديمة تحصل على ثيم تلقائي أيضًا بدون ترحيل بيانات Firestore.
- معاينة مزود الخدمة تعرض نفس الثيم الذي سيراه العميل.
- جميع الثيمات مخزنة محليًا داخل تطبيق Android كنسخة احتياطية، والسيرفر يبقى المصدر الأول.

## النشر
انشر ملفات الويب فقط:

```bash
firebase deploy --only hosting
```

لا تحتاج هذه الميزة إلى Cloud Functions أو تعديل قواعد Firestore.
