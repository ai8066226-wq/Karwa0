# Karwa Phase 78 / 2.2.9 — بدون Cloud Functions

هذه الحزمة تعمل بدون مجلد Functions وبدون استدعاءات Callable.

- إنشاء الطلبات وقبولها وتحديث حالتها يتم مباشرة عبر Firestore Transactions/Batch مع حماية `firestore.rules`.
- منع تكرار طلب الشحن يبقى عبر `topupLocks` وقواعد Firestore.
- SOS ومشاركة الرحلة وتقييم العميل من الكابتن أصبحت عمليات Firestore مباشرة ومقيدة بالقواعد.
- إشعارات الطلبات داخل التطبيق وإشعارات Android المحلية الناتجة عن مستمعات Firestore تبقى فعالة ما دام التطبيق/العملية تعمل.
- لا يوجد إرسال FCM تلقائي من الخادم عند إغلاق التطبيق بالكامل، لأن ذلك يحتاج جهة خادمية موثوقة لإرسال FCM.

## النشر
1. انشر `firestore.rules`.
2. انشر Hosting من هذه الحزمة.
3. لا يوجد أي مجلد Functions ولا حاجة إلى نشره.
