# كروة Phase 70 — سجل الإلغاءات الاحترافي

تم توحيد الإلغاء في التكسي والتوصيل والخدمات الأخرى.

- سبب الإلغاء أصبح إلزاميًا عند الإلغاء من العميل أو الكابتن أو مزود الخدمة أو الإدارة.
- تحفظ العملية: UID، الاسم، البريد الإلكتروني، نوع الحساب، سبب الإلغاء، ووقت الإلغاء.
- أضيفت للكابتن إمكانية إلغاء طلبه النشط مع تحرير حالة الانشغال في نفس المعاملة.
- أضيف لمزود الخدمة زر إلغاء الطلب المقبول؛ وإذا كان هناك طلب توصيل مرتبط يتم إلغاؤه أيضًا في نفس الدفعة.
- لوحة الإدارة تحتوي قسم «سجل الإلغاءات» مع فلتر حسب عميل/كابتن/خدمات/إدارة.
- السجلات القديمة تظهر مع أفضل بيانات متاحة، بينما جميع الإلغاءات الجديدة تسجل البيانات الكاملة.
- Firestore Rules تمنع تزوير UID/الاسم/البريد للإلغاءات الصادرة من الحسابات العادية، وتفرض سببًا بطول 3–300 حرف.

## النشر
ارفع ملفات السيرفر ثم انشر `firestore.rules` الجديدة. إذا كنت تستخدم Firebase CLI:

`firebase deploy --only hosting,firestore:rules`
