Karwa Phase 62 — نشر ميزة بلاغات الطريق بدون Cloud Function

1) افتح Terminal داخل هذا المجلد.
2) سجّل الدخول إلى Firebase CLI إن لم تكن مسجلًا.
3) نفّذ:

   firebase deploy --only hosting,firestore:rules

لا تحتاج إلى نشر Cloud Functions لتشغيل تحقق بلاغات الطريق في Phase 62.
هذه الحزمة لا تحتوي على Functions ضمن إعداد النشر.

ملاحظة: وظائف كروة الأخرى المنشورة مسبقًا (مثل الإشعارات الخلفية أو عمليات أخرى) لا يتم حذفها بهذا الأمر، لأنها ليست ضمن عملية النشر أعلاه.
