# كروة Phase 63 — اتصال الخلفية المستمر

- التطبيق لا يعيد تحميل WebView بمجرد العودة من الخلفية.
- فحص `version.json` فقط، وإعادة التحميل عند وجود إصدار سيرفر جديد فعليًا.
- Android يحافظ على جلسة التطبيق بخدمة Foreground منخفضة الإزعاج حتى إزالة التطبيق من شاشة التطبيقات الأخيرة.
- إذا تغيّرت الشبكة، يتم إعلام طبقة الويب ويترك Firebase يعيد الاتصال تلقائيًا دون إعادة بناء الصفحة.
- لا يحتاج هذا التعديل أي Cloud Function.

لنشر الواجهة والقواعد:

`firebase deploy --only hosting,firestore:rules`
